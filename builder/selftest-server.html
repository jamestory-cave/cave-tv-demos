Cave Builder self-test: hotel server

Checks the Builder against the Cave server it is served from, without changing anything: the published content round-trips through the editor model, the files the TVs read have the right caching and byte ranges, a stale draft save is refused, writes without the Builder's header or without signing in are refused, and an out-of-date publish is refused. Open it from the server, signed in (open the Builder first). On GitHub Pages use selftest.html.
