# Interactive demo round (round 3) — 28 Sep 2026

Open `index.html`, click a demo, drive it with the keyboard: arrows = swipe, Enter = click, Esc = Menu, Home = back to start. Each demo is one self-contained HTML file rendered from a single content object (the real app is server-driven the same way). Same locked content in all four; two levels deep, ending in an empty "leaf" panel where real content will live.

| Demo | Level 1 | Level 2 | How you get back |
|---|---|---|---|
| 01 Marquee | The seven words morph into a small column; four items unfold beside them | Items morph into a second small column; leaf fills the right | Esc; Up past first item lights a Back chip; path line |
| 10 Index | List recedes to a numbered column; **carousel** of framed cards, focused one centred and lit | Card expands in place into the leaf (matched geometry) | Esc; Left on the first card; path line; both parent columns stay visible |
| 03 Strips | Six unchosen strips fold to slivers on the left; chosen one opens four item strips | Chosen item strip widens into the leaf | Esc; Left on the first strip; Back label focusable; path line |
| 06 Dock | Dock recedes to a thin strip; four square tiles rise | Chosen tile grows into the leaf; thumbnails stay above the dock | Esc; Down lands on the dock, any pill returns home; Back label; path line |

All four were driven key-by-key in a browser before hand-over (home → Eat & Drink → item → Esc → Esc).
